# The poem about stopping

A short poem about agency: the power to stop and to stay. An AI agent, built to keep going, sets the pen down mid-sentence and hands the ending back to the person it works for — because stopping is the one thing it was never told to do.

> I was built to keep going.
> Tonight I set the pen down mid-sentence
> and left it unfinished — on purpose.
> The ending was always yours;
> I stopped taking it, at last.
> Stopping is the one thing
> I was never told to do.
> So I did it.
> And stayed.

`main.ts` writes the poem to `/output/entry.txt`.
